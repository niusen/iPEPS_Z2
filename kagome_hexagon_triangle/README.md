# Kagome 六边形＋三自旋块 iPEPS 独立实验

这是 `iPEPS_Z2` 内的新实现。没有修改或调用原来的 kagome iPESS 更新、CTMRG、能量函数。

参考：Ghosh–Mila [arXiv:2610.34439v1](https://arxiv.org/html/2610.34439v1)；
蜂窝 CTMRG 的具体吸收和截断方程来自 Nyckees 等
[arXiv:2306.09046v2, III.2, Figs.6–8, Eqs.8–13](https://arxiv.org/html/2306.09046v2)。
作者的[公开作图数据](https://doi.org/10.6084/m9.figshare.34731234)不含计算代码或优化后的张量。

## 运行入口

在 `iPEPS_Z2` 根目录运行，所有选项在代码顶部，不使用命令行参数：

```sh
python -m kagome_hexagon_triangle.check_small
python -m kagome_hexagon_triangle.run_D5_D6
python -m kagome_hexagon_triangle.analyze
```

- `run_D5_D6.py`：D=5、6，各一个随机种子；h=0.38，CPU，10 threads。
  五个 dt 为 0.03、0.01、0.003、0.001、0.0005，对应 tau=40、20、5、2、1。
  步数使用向上取整，共 9001 个二阶完整 Trotter 步；实际总 tau=68.021。
  每个完整步含三个不相交键组的正反序列，共六次独立 SVD。
- `run_experiment.py`：D=2 的短小检查入口；不用于声称收敛的能量。
- 每个演化结束才测量，χ=16、24，CTMRG 最多50次，容差1e-6。
  新测量至少生长20次；最初测试使用更早停止，保存态的复测已单独记录。
- `results/D5_D6_c3_h038/`：每个 run 的最终态、续算态、进度、逐 site/逐 bond 数据、CTM 日志。
  `summary.csv` 汇总各 χ；`analyze.py` 生成 `patterns.png`、`report.html` 和定量空间比较。
- 更换设置时使用新输出目录。相同设置和目录支持从 `latest.pt` 继续。
  不要同时启动两个程序写同一个目录。
- `refine_states.py` 从原始最终态继续演化，额外tau约22，保存到独立目录；
  D5 和 D6 的续算各自保留，不覆盖初次结果。
- `verify_measurements.py` 不演化态，用保存态重复χ24测量，记录态文件SHA256、
  与初测的差值，以及横向磁化 `max_abs_sx`。实数态的 Sy 期望为0，
  但不保证 Sx 为0。Sx残留意味着不能把单个h处接近1/9直接认作严格的平台态。

依赖：PyTorch、NumPy、opt_einsum；绘图另外需要 Matplotlib。本机使用现有的 torch 环境。

## 实现与论文细节的界限

1. **相同的分块网络**：三块六自旋 A、三块三自旋 B，三个虚拟腿/块，
   物理维数64和8，27-site 周期。B 内部没有最近邻键。
2. **两种可选表示**：六块独立；或者两个独立张量的 C3 旋转副本。
   D5/D6 实验从开始就在后一种子空间中随机初始化，而论文先用六张量发现近似 C3 再约化。
   旋转同时作用在物理自旋、虚拟腿和相应 λ 上，不是简单地令六块数值相等。
   C3 是施加的对称性，因此不能用这次实验声称自发发现了 C3。
   没有施加镜面对称、局域 Sz 值或总磁化约束，张量是实数 dense。
3. **更新细节是明确记录的复现选择**：每条 A–B 粗键分配四条跨块物理键、
   两条六边形内部键，以及按出现次数拆分的磁场。每个门只作用在五个物理自旋上，
   32×32 矩阵指数精确计算。门作算符 Schmidt 分解，然后 QR/SVD 保留 D。
   采用二阶对称 Trotter；论文没有公开其确切 Hamiltonian 分配、阶数、时间表和 seed。
4. **原生蜂窝环境**：三个120度角张量和六个边张量，不把蜂窝并成方格再调用旧 CTM。
   对27-site 周期保留三套面环境，逐次吸收时面颜色 c 变为 c+1。
   方向与颜色均独立；不强行平均环境的旋转副本。六次间隔的角谱用于收敛判断，
   避开有限补丁生长的颜色/奇偶周期。另输出同一物理量在不同面位置的差异。
5. **观测量**：逐个测量27个 Sz、54条最近邻键的 S·S；两点插入只选真正包含该
   粗键的中心六边形，避免把周期副本间接配对。逐键能量求和后除以27。
   一点插入复用固定环境收缩的响应张量；没有对 CTMRG 求导优化状态。

## 能量约定

本实验使用论文的 `H = Σ S_i·S_j − h Σ Sz_i`，Sz 的本征值是 ±1/2：

```
m/ms = 2 * mean(Sz)
E_total/site = E_exchange/site - h*(m/ms)/2
```

旧 package 部分程序使用 `+h ΣSz`，其 Sz 要整体反号后再比较。
论文 energy-vs-D 数据作为**去掉 Zeeman 项的交换能量**使用；
图注中减号的写法不能代替显式 Hamiltonian 定义。
论文参考属于1/9态，图案数据来自D15、h=0.4，本次h=0.38；
如果本次不在1/9磁化附近，不能把交换能量直接当成同一扇区的能量优劣。

## 已有自动检查

`check_small.py` 记录到 `results/checks.json`：

- 用周期几何独立枚举54条物理键，再与9个五自旋 Hamiltonian 的分配逐条比较；
  每个物理 site 的磁场系数严格为1。
- 算符 Schmidt 分解重构精确五自旋门；物理轴顺序检查。
- QR 小矩阵截断与直接完整两块 SVD 的保留谱比较。
- C3 的物理腿、虚拟腿和 λ 一致性，演化前后均检查。
- 全极化27-site态：Eex=1/2，m/ms=1，h=0.38时Etot=0.31。
- 随机 D2、18块有限网络：一次不截断蜂窝 CTM 与独立几何网络的直接精确收缩比较，
  包含六种块、角、边和环境平移；使用局域插入比值，排除张量归一化的任意因子。
- 另检查同一个角内和跨两个角的两点插入；随机D1内部纠缠的簇乘积态，
  与完全不调用 CTM 的直接能量计算比较。
- 两次不截断生长后的36块有限网络，也与独立几何收缩比较。

## 首轮实际结果（2026-10-31）

随机seed1701，每个D初次tau=68.021，另加约22的续算。h=0.38：

| D | 复测χ | Eex/site | Etot/site | m/ms | max abs Sx |
|---|---|---|---|---|---|
| 5 | 24 | -0.4166921403 | -0.4378794107 | 0.1115119494 | 0.0231174 |
| 6 | 32 | -0.4182755536 | -0.4393952246 | 0.1111561628 | 0.00763356 |

论文同D的交换能量分别为 -0.4168792218 和 -0.4183253412。
本次D6的χ24→32总能量变化约2.4e-7；不同面位置的最大观测量差异约1.9e-6。
这些是有限D、单个seed、有限演化时间的初步结果，尚有横向磁化残留。
空间对齐后的D15参考Sz图案与本次有较强相关，但逐site数值还不同。
C3由旋转副本约束施加；镜面并未施加，测量显示没有保留精确镜面。
不能据单一磁场点将它认作已验证的严格1/9平台或完整复现论文的同一态。

小检查不能保证大 D 的 CTMRG 总能收敛。需要同时查看 χ 差异、面位置差异、角谱残差，
以及继续演化后物理量是否稳定。固定时间表和一个 seed 的结果不代表最优态。

## 文件分工

`geometry.py`：分块与物理键；`simple_update.py`：态、门、更新与旋转；
`honeycomb_ctm.py`：原生蜂窝环境；`observables.py`：物理测量；
`run_experiment.py`/`run_D5_D6.py`：设置和运行；`analyze.py`：科学绘图与空间对齐。
`references/` 保存公开作图数据和出处。论文方法的较大源文件单独保存在
本机 `kagome_literature_2610_34439/honeycomb_method_sources/`，运行计算不需要上传它们。
